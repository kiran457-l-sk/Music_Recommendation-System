# Music Recommendation System

I have bult this recommendation system  mainly as part of my nlp project.
# Dataset
**Source:** Kaggle:https://www.kaggle.com/datasets/joebeachcapital/30000-spotify-songs
**Size:** 32833rows,33 columns
**Key Columns:** 'track_name', 'track_artist', 'playlist_name', 'playlist_genre',
       'playlist_subgenre', 'dance_tag', 'acoustic_tag', 'tempo_tag',
       'mode_tag', 'energy_tag', 'valence_tag', 'loudness_tag', 'instr_tag',
       'live_tag', 'key_tag
## Methods       
 - Clean the data(handled missing values)
 - Text preprocessing(removing unwanted tags,emoji)
 - Feature selection
 - NlP concepts
